# Spanish-to-english
A small translator app that translates spanish to english.
I wanted to start a simple project related to something that I was familiar with. I chose this particular project as my first project because of simple reasons , I was familiar with Spanish as I had been learning it for about 2 years now and the dataset of spanish to english was something I could easily find. NLP on the other hand is something that had always fasicanted me so I took the knowledge I had of python to create this small experiment , there might not be anything new in it but it's mine. 
The dataset has been taken from https://www.manythings.org/anki/.
